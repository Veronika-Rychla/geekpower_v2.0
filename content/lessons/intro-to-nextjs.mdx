Welcome to your first lesson! Next.js's **App Router** organizes your app
around folders in the `app` directory — each `page.tsx` file becomes a route.

## What you'll learn

- How routes map to folders
- Server vs. Client Components
- How this lesson itself is rendered

## Server vs. Client Components

Components are **Server Components** by default — they run on the server and
never ship JS to the browser. Add `"use client"` at the top of a file when you
need interactivity, like the quiz below.

## Embedding media

Lessons can embed native media directly:
